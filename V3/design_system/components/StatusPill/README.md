# StatusPill

One or two words of state. The colour always has a meaning and the pill always carries the word.

- **Primary container**: done, published, passed, operational, for review.
- **Attention** (`accent3` / `accent4`): needs fix, overdue, needs revision.
- **Error container**: real failures only (failed, grounded).
- **Neutral** (`tertiary`): draft, pending, in maintenance.

Add an 8px dot when the pill sits in a dense table. In-progress uses the `inversePrimary` dot on a neutral pill. There is no green in this system.
