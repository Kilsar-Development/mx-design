# SegmentedControl

Switches between two to four views of the same place: Guided / Quick checklist, Oral / Written, Blocks / Block templates / Modules.

The track is `tertiary`; the selected segment is `surface` with `mx-drop-shadow`. Use the pill form in page headers and the block form (`medBorderRadius` track, `smallBorderRadius` segments, equal widths) inside drawers.

Not for filters (use FilterChip) and not for steps in a flow (use Stepper).

Both forms are 36px tall with 30px segments. The pill form is fully rounded (track radius 18, segment radius 15).
