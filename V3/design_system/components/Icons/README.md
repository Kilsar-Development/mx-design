# Icons

The icon set drawn for the mock: 24px grid, 1.8px stroke, round caps and joins, no fill, coloured by `currentColor`. Shown at 18px in the rail and 14 to 16px in buttons.

These are single-path drawings made for this prototype, not a licensed icon library. The Assistant destination uses the Orion mark (see the Icons asset group) and not a stroke icon.
