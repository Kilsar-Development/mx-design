# IconButton

A square button that carries only an icon. Give every one an accessible name and a tooltip.

- **Outline** (36px, or 32px in rows): 1.5px `outline` border, icon in `onSurfaceVariant`; border and icon turn `primary` on hover. Used for edit, history, present, worklog.
- **Close**: a 32px `tertiary` circle with ✕, top right of drawers and dialogs.
- **Ghost** (32px): no border, `tertiary` on hover. Used inside list rows for move up, move down and remove.

Remove and delete are always the trash icon, never the word "Remove" or a ✕.
