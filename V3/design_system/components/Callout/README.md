# Callout

A block of supporting information inside a pane.

- **Orion**: a 1.5px `primary` outline with an `overlineBold` "Orion ·" title, set uppercase. What the assistant found, with the quoted source highlighted in `primaryContainer`.
- **Notice** (`accent3` / `accent4`): something the user must know before acting.
- **Confirmed** (`primaryContainer` / `onPrimaryContainer`): a check has passed.

One sentence or two. A callout explains; it never holds the action.
