# FilterChip

A pill above a table that narrows what it shows. Off is `tertiary` with the filter name and ▾; on is `primaryContainer` with the chosen value and ✕.

Chips sit in one row, left of the "n of m" count. In the mock a chip cycles through its values on click; the product opens a menu. Filters that accumulate several values (ACS codes) show each value as its own removable pill after the chip.
