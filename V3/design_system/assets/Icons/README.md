# Icons

`orionOutline.png` is the Orion mark, 96 by 96px. Use it as a CSS mask over a block of colour, never as a plain image, so it takes the same colour as the icons beside it: `primary` when its rail item is selected, `onSurfaceVariant` otherwise, `onSurface` inside a secondary button.

The stroke icons for every other destination are in the Icons component.
