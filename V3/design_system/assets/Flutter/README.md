# Flutter

`color_scheme.dart` holds the primitives (`ColorPalette`), the light and dark `ColorScheme`, and the `AccentColors` theme extension. `scheme.json` holds the same values as data.

The colour tokens in this system hold the same values under the same names. If one changes, change all three.

The Dart `ColorScheme` here sets 34 of the 46 allowed members. The 12 Fixed members are not set in it.
