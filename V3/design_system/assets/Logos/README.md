# Logos

`kilsar-mark.svg` is the Kilsar mark, one colour. The supplied drawing takes its colour from the text around it, which a picture file cannot do, so this copy is filled with the light value of `onSurface` (#1b1d20). In the product, set it in `onSurface` so it follows the theme.

The Mx Web mock does not place the mark, so there is no clear-space or minimum-size rule yet.
