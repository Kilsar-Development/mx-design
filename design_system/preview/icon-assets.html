Icon assets

Everything in assets/icons/. Rendered as a CSS mask so any glyph takes a token color.

Added for app gaps

Shipped to close DS-UPDATES items 5, 6, 8, 9, 10, 14 and 15, where apps were inlining SVG or masking a semantically wrong glyph. These ten are SVG, not PNG — same mask-image contract, so KlsIcon consumes them unchanged, but pass the .svg extension. plus is the canonical leading glyph for Add <thing> actions (see buttons-primary.html) — never a "+" text character.

Core set

Usage — mask the asset and set background: currentColor (or a token) so one file serves every theme and state:
-webkit-mask: url(assets/icons/eye.svg) no-repeat center / contain; background: var(--kls-on-surface);
Default render is 24px at the icon's own stroke weight; 18px is the dense/in-button size, 16px for text buttons. Only chevronDown ships — rotate it for the other three directions.
